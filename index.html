1. Modelo híbrido (como funciona hoje)

O site não foi apagado e remontado do zero no Elementor. Ele usa um modelo seguro:

Se a página foi salva com “Editar com Elementor” → o site mostra o conteúdo do Elementor.

Se a página ainda não foi montada no Elementor → o site mantém o layout PHP do tema Telefer (o visual atual).

Assim a Home, Sobre, Soluções etc. continuam no ar enquanto cada página é migrada no builder.

O plugin Elementor já está instalado em produção. O tema Telefer (versão 1.10+) reconhece páginas feitas no Elementor.

3. Entrar no painel

  1. Abra https://telefer.com.br/wp-admin/.
  2. Informe usuário ou e-mail e senha.
  3. Clique em Log In.

Quem ainda não tem usuário: peça ao admin do site (V4) para criar conta com perfil Editor ou Administrador.

4. Editar uma página com Elementor

Use este fluxo quando for migrar ou alterar uma página institucional no Elementor.

4.1 Abrir a página

  1. No menu esquerdo: Páginas → Todas as páginas.
  2. Abra a página desejada (ex.: Contato, Sobre nós, Home).
  3. Clique em Editar com Elementor.

4.2 Montar ou alterar seções

  1. No painel esquerdo do Elementor, arraste widgets: Título, Texto, Imagem, Botão, etc.
  2. Clique em qualquer texto/imagem já existente para editar.
  3. Use seções e colunas para organizar o layout (hero, cards, CTA).
  4. Cores da marca: azul #15325f / #004ca0 e amarelo #fdb813.

4.3 Publicar e conferir

  1. Clique em Publicar (ou Atualizar).
  2. Abra a URL pública da página.
  3. Faça hard refresh: Windows Ctrl+F5 · Mac Cmd+Shift+R.
  4. Se o cache mostrar versão antiga, acrescente ?telefer_nocache=1 na URL.

Importante: na primeira vez que você publicar uma página no Elementor, o layout PHP daquela página deixa de aparecer e passa a valer o que estiver no builder. Monte as seções principais antes de publicar, ou use Visualizar / rascunho enquanto constrói.

5. Usar o template Elementor Full Width

O tema tem um modelo específico para páginas 100% Elementor, mantendo o header/rodapé Telefer:

  1. Abra a página no editor do WordPress (não no Elementor ainda).
  2. No painel direito: Atributos da página → Modelo.
  3. Escolha Elementor Full Width.
  4. Salve / Atualize.
  5. Depois clique em Editar com Elementor.

As páginas institucionais atuais (Home, Sobre, Cloud…) já têm lógica híbrida nos templates próprios. O Full Width é útil para páginas novas.

6. Blog (continua no WordPress)

Artigos do Blog não dependem do Elementor:

  1. Posts → Adicionar novo.
  2. Preencha título, texto, resumo (Excerpt), categoria e imagem destacada.
  3. Categorias oficiais: Telefonia, Automação, Marketing Digital, Dicas, Finanças.
  4. Publicar.

7. Header, rodapé e menu

Hoje o menu (Home, Sobre, Soluções, Blog, Contratar, Contato), o logo e o rodapé vêm do tema Telefer, não do Elementor.

  • Soluções ativas no menu: Telefer Cloud e Telefer com IA.
  • Presença Digital foi retirada; quem acessar a URL antiga vai para /solucoes/.

Para editar header/rodapé visualmente no Elementor no futuro, seria necessário Elementor Pro (Theme Builder). Por enquanto, alterações de menu/header passam pelo tema.

8. Voltar ao layout antigo de uma página

Se uma página foi publicada no Elementor e você quiser restaurar o visual PHP do tema:

  1. Abra a página no WordPress.
  2. Em Elementor (ou nos metadados da página), limpe / desative o modo builder — ou exclua as seções e volte o conteúdo ao modo clássico, conforme a versão do Elementor.
  3. Forma prática: no editor Elementor, use o histórico / limpe o conteúdo e não deixe a página marcada como construída no Elementor; depois atualize.
  4. Confirme no site com ?telefer_nocache=1: se não houver builder ativo, o tema PHP volta a aparecer.

Em caso de dúvida, piece rollback do tema (seção abaixo) — o backup pré-Elementor está guardado.

9. Backup e rollback do tema

Antes da ponte Elementor, foi feito backup completo do tema:

  • Servidor: wp-content/themes/telefer-pre-elementor-20261014/
  • Arquivo: public_html/_backups/telefer-theme-pre-elementor-20261014-165906.tar.gz

Rollback de emergência (FTP):

  1. Renomeie themes/telefer → themes/telefer-elementor-wip
  2. Renomeie themes/telefer-pre-elementor-20261014 → themes/telefer
  3. Atualize o site com ?telefer_nocache=1

10. Checklist rápido

Alterar texto/imagem de página já no Elementor: Páginas → abrir → Editar com Elementor → alterar → Atualizar → hard refresh.

Migrar página que ainda está em PHP: Páginas → Editar com Elementor → montar seções → Visualizar → Publicar.

Artigo do Blog: Posts → Adicionar novo → categoria + imagem destacada → Publicar.

Conferir cache: acrescente ?telefer_nocache=1 na URL.

Soluções no menu: só Cloud e Telefer com IA.

Ordem sugerida para migrar páginas

  1. Contato (mais simples)
  2. Soluções (hub)
  3. Telefer Cloud
  4. Telefer com IA
  5. Sobre nós
  6. Home (mais complexa — deixe por último)
